i

about

this site is laid out as a field guide because everything i make turns out to have an animal in it.

i'm chelsea. i live on the edge of the forest of dean and i've spent the last decade doing communications for a council, an events agency and a global hosting company. the thread through all of it is people: finding the ones who care about a thing and giving them somewhere to be.

the day job is pr and social at scale, and the bits of it i invented for myself: a youtube channel, a newsletter, an in-person website week for the co-working space over the road. off the clock i've spent fifteen years moderating odd corners of the internet, i help run a 3,500-person convention, and i build the tools i wish existed. i'm a chartered pr practitioner, an illustrator by training, and the person who ends up holding the clipboard.

also: woods, rivers, racecars.

  • i set a goal before i start anything, then report what happened.
  • i notice the gap, sketch it, pull in whoever's needed, and ship it.
  • posthog on everything from day one.
  • i write the docs first.

iii

specimens

the two i built for myself.

whimsee

live on ios + android

why
i wanted an app that sends you outside instead of keeping you in. you hide a small note where you stand. only someone who walks there can read it. no feed, no algorithms, no infinite anything.
distinguishing marks
postgis decides whether you're actually there. row level security keeps every note dark until you are. edge functions do the rest.
diet
expo / react native · next.js on cloudflare workers · supabase · posthog
habitat
wherever you happen to be standing.

jackdaw

closed beta

why
nobody's coming to run your socials. jackdaw drafts posts in your voice, you veto every one, and it learns what lands.
distinguishing marks
one typescript core under both faces. claude writes per-platform captions, headless chromium renders the carousels, and publishing is idempotent across ten platforms, so a retry never double-posts.
diet
typescript / node · telegram bot + web app · claude api · headless chromium · posthog
habitat
telegram, and a web app for bigger screens. the early queue is open.

sightings

things i've left out in the open.

  1. pressed-hog

    a hedgehog with a wordpress plugin in it. wires posthog into wordpress properly: session replay, surveys, woocommerce events, consent modes, a reverse proxy that ad blockers don't clock, and analytics inside wp-admin.

  2. courser-calculator

    horse genetics for a horse rpg i play. rolls four foals from two parents, then lists every foal the pairing could ever produce. runs entirely in your browser. have a go.

    marshal signups for motorsport events, self-hosted. invite links, licence uploads, team rosters, and a dashboard for whoever's holding the clipboard.
